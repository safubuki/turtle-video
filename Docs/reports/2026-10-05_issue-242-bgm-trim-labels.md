# Issue #242: BGMの現在位置を開始点・終了点へ設定する表示

## 対応

[Issue #242](https://github.com/safubuki/turtle-video/issues/242) に対応し、BGMのトリミング操作を次の表記へ変更した。

| 変更前 | 変更後 |
| --- | --- |
| 開始設定 | 音源の現在位置を開始点に |
| 終了設定 | 音源の現在位置を終了点に |
| 現在のBGM位置を反映 | 音源内の現在位置: 2.5秒（現在値の表示例） |

現在の音源位置をボタンの上に表示し、数値入力欄と同じ `formatTimeStepperInput` で秒数の精度を揃えた。ツールチップにも同じ秒数を表示する。

補足説明は「開始点から終了点までの音源をBGMに使います。動画上の配置は『開始位置』で調整します。」とした。設定後の値は既存のトリミング開始・終了欄で確認できる。ヘルプ本文と操作見本も同じ表記に揃えた。

ボタンは高さ44px以上とし、コンテナ幅に応じて折り返す。見えるラベルをそのままアクセシブル名として使用する。

## 影響範囲

- 対象はstandard（Android / PC）の複数BGM UI。
- 既存の `resolveAudioClipSourceTimeAtTimelineTime` で音源内の位置を計算し、`setBgmClipTrimAtSourceTime` で開始点・終了点を設定する処理を使用する。
- 区間外・最小尺・ロック時の無効化と、単発編集前のプレビュー停止を維持する。
- 音声ストア・再生・書き出し・保存形式・apple-safariの単一BGM UIへの変更はない。
- `spec.md` とオーバービューの実装パターン13-268へ、音源の使用範囲と動画上の配置の区別を追記した。

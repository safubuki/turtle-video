# Turtle Video v6.0.0 リリースノート

- **リリース日**: 2026-08-10
- **前バージョン**: v5.3.0（2026-06-07）
- **コミット数**: 79

キャプション機能を大幅に強化し、トランジション・ぼかし・回転・倍速といった映像表現を追加しました。あわせてウォーターマークとエンドロールロゴ、ナレーションの波形表示と無音区間ナビ、書き出しの品質・向き設定と GPU 処理対応など、v5.3.0 以降の主要な機能追加と安定化を取り込んでいます。

---

## ハイライト（アプリ内「前回タグからの主な変更」に掲載）

| # | 項目 | 内容 |
|---|------|------|
| 1 | キャプションの大幅強化 | 複数行をまとめて登録できる一括入力、背景帯、タイミングの自動調整に対応し、ナレーションからキャプションを自動生成できるようになりました。 |
| 2 | 映像表現の追加 | クリップ間のトランジション、ぼかし、回転、倍速再生に対応し、演出の幅を広げました。 |
| 3 | ウォーターマーク／エンドロールロゴ | 動画にウォーターマークやエンドロールのロゴを重ねられるようになりました。位置調整は中央を原点とした操作に統一しています。 |
| 4 | ナレーション波形と無音区間ナビ | ナレーション音声を波形で表示し、無音区間を自動検出します。前後の無音へ素早く移動でき、タイミング合わせが簡単になりました。 |
| 5 | 書き出しの品質・向き設定と GPU 処理 | 書き出しの画質と動画の向き（縦横）を選べるようになり、GPU 処理に対応して書き出しを高速・安定化しました。 |
| 6 | Bug Fix | 書き出し映像の乱れや動画のつなぎ目のズレ、書き出し中の処理待ち、プレビューの表示残りなど、複数の不具合を修正しました。またスライダーに −/+ ボタンを追加し、スマホでの微調整をしやすくしました。 |

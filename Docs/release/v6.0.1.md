# Turtle Video v6.0.1 リリースノート

- **リリース日**: 2026-08-11
- **差分起点**: v5.3.0（メジャーリリースからの累積差分）
- **直前リリース**: v6.0.0

v5.3.0以降に追加された編集機能を維持しながら、書き出しのフレーム連続性、エンコーダ待ち、複数回実行時のメディア解放を見直しました。固定30fps出力を維持し、トランジション編集時のプレビュー停止も追加して、動画品質と操作の安定性を高めています。

---

## v5.3.0以降の主な機能

- キャプションの一括入力、背景帯、タイミング自動調整、ナレーションからの自動生成
- クリップ間トランジション、ぼかし、回転、倍速再生
- ウォーターマーク、エンドロールロゴ、中央原点による位置調整
- ナレーション波形、無音区間の自動検出と前後移動
- 書き出し画質・向き設定、GPU処理、固定30fps出力
- サムネイル、プロジェクトポスター、自動保存、スマートフォン向け操作性改善

## v6.0.1 の変更

### エクスポートの連続実行安定化

- VideoEncoderのライフサイクルと終了処理を整理し、video/audioのflush・close順を保証。
- backpressure発生時にタイムラインとCanvas描画を同期して待機し、フレーム欠落、重複、末尾補完、音声・映像のずれを防止。
- エクスポート終了後に共有video/audio要素と古いデコーダ参照を解放してから再マウントし、2回目以降の書き出しやプレビューへの影響を抑制。
- 実機ログで固定30fps・全フレーム出力・A/V終端一致を確認。品質保護のため、queue上限、bitrate、backpressure同期は維持。

### 固定30fps出力の整理

- 24fps素材に合わせて出力fpsを変える実験的対応を取り下げ、既存の固定30fps出力へ戻しました。
- 可変fps化によるカクつきや再生互換性のリスクを避け、プレビューと書き出しのタイムラインを一貫させています。

### トランジション編集時のプレビュー安定化

- 通常プレビュー再生中にトランジション設定を開く、種類を変更する、時間を変更する操作の直前に再生を一時停止。
- ディゾルブによる総尺・境界変更を再生ループへ安全に反映し、設定中に完全ブラックアウトしたまま再生が続く問題を防止。

### 診断ログの正確性改善

- standard版のCanvas直接キャプチャログを正しい実行環境名で記録。
- `[DIAG-9]` の最終ファイルサイズをカバーアート適用後のBlobサイズとして記録し、mux直後のサイズと適用有無を分離。

## 既存出力への配慮

- 出力解像度、固定30fps、エンコードbitrate、音声合成、保存形式は維持しています。
- 24fps素材を30fpsへ変換する際の孤立した同一フレームは変換上発生し得ますが、長時間の静止や累積した時間ずれを追加しません。
- 通常プレビューの音量など連続値の調整は従来どおり、操作中に一律停止しません。

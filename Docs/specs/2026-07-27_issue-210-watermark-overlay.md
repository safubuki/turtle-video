# Issue #210: 範囲指定ウォーターマーク・ブランドロゴ

## 仕様書

### 概要

プロジェクト全体の時間軸に対して 1 件の画像オーバーレイを設定し、動画・画像カードの境界をまたいでプレビューと書き出しへ同じ見た目で合成する。

### 要件一覧

| # | 要件 | 優先度 | 説明 |
|---|---|---|---|
| R1 | 画像選択 | 必須 | PNG / JPEG / WebP を 1 件選択できる |
| R2 | 独立タイムライン | 必須 | カード配列へ入れず、プロジェクト時間の開始・終了で管理する |
| R3 | 見た目調整 | 必須 | X/Y、自然サイズ基準の倍率、透過度、回転をスライダーと数値入力で調整する |
| R4 | マスク | 必須 | 四角、角丸、円形と、画像領域に対するマスクサイズを調整できる |
| R5 | 周辺ぼかし | 必須 | マスク境界を 1080p 基準のフェザー量でぼかす |
| R6 | 表示保持 | 必須 | 非表示にしても画像と設定値を保持する |
| R7 | WYSIWYG | 必須 | standard / apple-safari の preview と export が共通描画関数を使う |
| R8 | トランジション耐性 | 必須 | クリップとトランジションの描画後に合成し、境界で消えない |
| R9 | 保存復元 | 必須 | 画像バイナリと全設定を手動保存・自動保存から復元する。旧データは空設定へ補完する |
| R10 | モバイル操作 | 必須 | 数値スライダーは `SwipeProtectedSlider` を使い、縦スクロール誤操作を防ぐ |

### データ構造

```ts
type WatermarkMask = 'rectangle' | 'rounded' | 'circle';

interface WatermarkOverlay {
  file: File | null;
  url: string | null;
  enabled: boolean;
  startTime: number;
  endTime: number;
  positionX: number;
  positionY: number;
  size: number;
  opacity: number;
  rotation: number;
  mask: WatermarkMask;
  maskSize: number;
  feather: number;
}
```

保存形式では `file` / `url` の代わりにファイル名、MIME、更新日時、`ArrayBuffer` を保持する。

### UI

- 「動画・画像」カテゴリー内のカード一覧先頭に、初期状態が閉じた「ウォーターマーク」設定を置く。見出しはアイコンなしの文字だけとし、独立カテゴリーにはしない。
- 未選択時は用途と対応形式を示す空状態と「画像を選択」ボタンを表示する。
- 選択後はサムネイル、表示トグル、画像変更・削除、表示範囲、位置、倍率、透過度、回転、マスク形状・サイズ、周辺ぼかしを段階的に表示する。
- 現在のプレビュー位置を、既存カードと同じラベル・ピンアイコン付き開始／終了ボタンで反映できる。
- 位置調整の直下に「左下、右下、中央、左上、右上」の簡単設定を置く。通常は左右 9/91%、上下 15/85% を基準位置とし、画像倍率、マスクサイズ、回転、周辺ぼかし後の可視範囲が大きい場合だけ、見切れすぎないよう中央側へ補正する。
- 見た目の各項目には個別リセットを設ける。既定は中央（X/Y 50%）、自然サイズ 1 倍、透過なし、回転なし、四角マスク 100%、周辺ぼかしなし。

## 実装計画

### Phase 0: データ契約

- 型、正規化ユーティリティ、Zustand ストアを追加する。
- Object URL は置換・削除・復元時に必ず解放する。

### Phase 1: 永続化

- `ProjectData` に任意フィールドを追加する。
- 手動・自動保存、読込結果、自動保存ハッシュ、全クリアへ接続する。
- 旧保存データは画像なしの既定値へ補完する。

### Phase 2: 共通描画

- 時間範囲判定、変形、マスク、フェザーを純粋な共通描画ユーティリティへ集約する。
- standard / apple-safari 両 flavor でタイトル描画後に呼ぶ。
- 凍結レガシーは契約シグネチャのみ追随する。

### Phase 3: UI 統合

- `OverlaySection` を `React.memo` で追加する。
- ファイル形式検証、スライダー + 数値入力、アクセシブルなラベル、空状態を実装する。
- TurtleVideo で画像要素 ref と編集コールバックを配線する。

### Phase 4: 品質確認

- 正規化、時間範囲、描画、ストア、保存復元、UI、両 flavor 契約のテストを追加する。
- `npm run test:run`、`npm run lint`、`npm run build` を実行する。
- オーバービューの機能一覧と実装パターンへ追記する。

# 動画・画像カードの折りたたみとプレビュー追従

## 仕様書

### 概要

動画・画像の各カードは、普段は折りたたんで並びが分かるようにする。プレビュー位置の1枚をフォーカスし、スライダーを手動で動かしたときと追加のときにそのカードを開く。再生が終端まで進んで止まっても、カードは開かない。自分で開いたカードは、フォーカスが移っても開いたままにする。

開閉は編集セッション中の表示状態であり、プロジェクトの保存データには入れない。

### 背景・課題

カードは表示区間（動画のトリミング、画像の表示時間）を常時開いていた。枚数が増えると1画面に1枚前後しか入らず、並び順と尺のバランスが見えない。一方で、常に閉じて始めると、プレビューを止めて直すたびに開く操作が増える。

位置・音量・再生速度は、もともとカード内のアコーディオンで閉じている。縦に伸びている本体は表示区間である。

### 対象

| 対象 | 扱い |
|------|------|
| 動画・画像セクションのクリップカード | この仕様の対象。standard / apple-safari の両方 |
| BGM、ナレーション、キャプション | 対象外 |
| 位置・サイズ・回転・ぼかし、音量・フェード、再生速度 | カードを開いても、各アコーディオンは自動では開かない |
| サムネイルのホバー拡大・タップライトボックス | 変えない。サムネイルは開閉に使わない |

### 要件一覧

| # | 要件 | 優先度 | 説明 |
|---|------|--------|------|
| R1 | カードの折りたたみ | 必須 | 閉じた行で並びを確認し、開いたカードで表示区間を編集する |
| R2 | 閉じた行の情報 | 必須 | 1行目は番号、サムネイル、ファイル名、ロック、移動、コピー、削除。2行目（その下）に開始・終了と尺。等倍でない速度とミュートも2行目。開いたカードでは2行目を出さない |
| R3 | 閉じたままの並べ替え | 必須 | 上へ、下へ、コピー、削除は閉じたままで操作できる |
| R4 | プレビュー位置のフォーカス | 必須 | 再生位置のカードに枠を付ける。区間判定はプレビューのアクティブクリップと同じ |
| R5 | 追従して開く | 必須 | スライダーの手動移動とファイル追加（複製・続きを追加コピーを含む）で、いま見る1枚を開く。再生の進行と終端停止では開かない |
| R6 | 再生中は高さを変えない | 必須 | 再生中の連続した進みでは開閉もスクロールもしない。枠だけが移る |
| R7 | 自分で開いたカードは残す | 必須 | 見出しで開いたカードと「すべて開く」で開いたカードは、フォーカスが移っても閉じない |
| R8 | 明示的に閉じたカードはすぐ開かない | 必須 | 再生位置のカードを閉じたあと、その区間にいる間は開き直さない |
| R9 | すべて開く / すべて閉じる | 必須 | カードが2枚以上のとき、見出しの直下・一覧スクロールの外に右寄せで置く。ロック中でも押せる |
| R10 | 保存しない | 必須 | 開閉は `MediaItem` にも保存ペイロードにも追加しない。読み込み直したときは再生位置のカードだけ開く |

### セクションの開閉

動画・画像の見出しは、BGM・ナレーションと同じように押して開閉できる。

- 起動時に動画・画像が1件も無いときは閉じている
- 保存プロジェクトを読み込んだとき、動画・画像があれば開く。無ければ閉じる
- ファイルを追加して件数が増えたときも開く
- 見出しの右にある向き、ロック、追加は、開閉とは別に押せる

### 画面

#### 閉じたカード

1行目は、番号、サムネイル、種類アイコン、ファイル名、個別ロック、上へ、下へ、コピー、削除。

閉じているときはサムネイルをタイトル行と時刻行の2行分（96×56）まで大きくし、何の映像かすぐ分かるようにする。時刻はタイトル文言の下に揃うよう右へ寄せ、タイトルもサムネイルから少し離す。

2行目は、そのサムネイルの右、タイトルとボタンの下に、タイムライン上の開始・終了と尺を折り返さず並べる（例: `00:12.0 - 00:18.0` と `6.0秒`）。動画で等倍でないときは `N倍`、ミュートのときは `ミュート` もこの行に置く。

開いたカードではサムネイルを従来の小さいサイズ（48×28）に戻し、タイトルもその横へ戻す。

開閉は矢印と2行目である。ファイル名はマウスオーバー、タッチではタップで全文をポップアップする。タッチでファイル名をタップしてもカードは開閉しない。サムネイル、ロック、移動、コピー、削除は開閉に使わない。

#### 開いたカード

2行目の区間と尺は出さない。動画は表示区間とトリミング、画像は表示時間を、閉じる前と同じ編集欄として出す。位置・音量・再生速度の見出しは従来どおり閉じた状態で戻る。ユーザーが以前開いていた内側のアコーディオンは、そのカードの既存状態のまま（保存されている `isTransformOpen` は変えない）。

複数のカードを同時に開ける。

#### フォーカス

プレビューの再生位置が含まれるカードに枠を付ける。判定は `findActiveTimelineItemWithTransitions` に合わせる。

- 区間は開始以上、終了未満
- ディゾルブで重なる区間は、後ろのカード
- 本編の終了時刻以降（終了ちょうど、エンドロール中を含む）は最後のカード
- 再生中も枠は再生位置に追従する
- 枠が付いたカードが画面の外にあるときは、スライダーを手動で動かしたときに、一覧の中だけそこまでスクロールする。再生中と、再生が止まって枠だけが移ったときはスクロールしない

#### すべて開く / すべて閉じる

「動画・画像」見出しの直下、カード一覧がスクロールする領域の上に、右寄せで1行置く。見出し右の向き切替・ロック・追加には置かない。

- カードが2枚以上のときだけ表示する
- セクションがロック中でも押せる
- 「すべて開く」は全カードの表示区間を開く。位置・音量・再生速度は開かない。開いたカードは、自分で開いたカードと同じ扱いにする
- 「すべて閉じる」は、自分で開いたカードも再生位置で開いたカードも閉じる。フォーカスの枠は残す

### 開閉の規則

カードが開いている条件は、次のどちらかである。

- 自分で開いた（見出しのトグル、または「すべて開く」）
- 再生位置について開いている（同時に1枚。追加直後の新しいカードを含む）

#### 開く

- 見出しを押すと、そのカードが開く
- 停止中にスライダーで別のカードへ移すと、移動先が開き、直前まで再生位置について開いていたカードは閉じる
- 再生中、および再生が終端や一時停止で止まったときは、カードを開かない。枠だけが再生位置に付く
- 再生中でも、スライダーで時刻が 0.5 秒以上飛んで別のカードへ移ったときは開く。フレームごとの進みでは開かない
- カードを1件追加、複製、続きを追加コピーしたときは、そのカードが「いま見ている1枚」として開く。直前まで再生位置について開いていたカードは閉じる。画面の外ならそこまでスクロールする
- 複数のカードを同時に追加したときは、最後のカードではなく、プレビュー位置のカードを開く。スクロールもそのカードへ行う
- カードが1枚のときは、再生位置がそこにあるので開いている

#### 自分で閉じる

- 開いているカードの見出しを、もう一度押すと、その1枚が閉じる
- 「すべて閉じる」で全部閉じる。枠は残る

再生位置のカードを自分で閉じたあとは、そのカードの区間にいる間は閉じたままである。同じ区間での一時停止やスライダー移動では開き直さない。別のカードへスライダーで移して戻ったとき、または別のカードへ 0.5 秒以上飛んだあとに戻ったときに、再び開く。再生がそこまで進んで止まっても、開き直さない。

#### 自動で閉じる

自動で閉じるのは、再生位置について開いていた1枚だけである。自分で開いたカードは、フォーカスが移っても開いたままである。

再生中にカードの境界をまたいだだけでは、開閉しない。同じカードの中で再生位置が動いただけでも、閉じることも開き直すこともない。

#### プロジェクトを開き直したとき

`restoreFromSave` で一覧が入れ替わったときは、開閉を捨て、再生位置のカードだけを開く。保存データには開閉を書かない。

### 動作例

カードが5枚あり、再生位置はカード1である。開いているのはカード1だけ。

1. カード3へシークする。カード3が開き、カード1は閉じる。
2. 見出しを押してカード5を開く。カード3とカード5が開いている。
3. カード4へシークする。カード4が開き、カード3は閉じる。カード5は開いたまま。
4. カード5の見出しをもう一度押す。カード5が閉じ、開いているのはカード4だけ。
5. カード4の見出しを押して閉じる。全部閉じる。枠はカード4に残る。カード4の区間内で止めても、開き直さない。
6. カード2へシークする。カード2が開く。

### 非要件

- 開閉状態の保存・復元
- BGM、ナレーション、キャプションのカード折りたたみ
- カードを開いたときに位置・音量・再生速度まで自動で開くこと
- 再生中にカードの高さを変えること
- サムネイル拡大の操作変更

### 実装メモ

- 状態は `ClipsSection` のセッション state。`pinnedIds`（自分で開いた一覧）と `followId`（再生位置について開いている1枚）と `suppressedFocusId`（明示的に閉じた再生位置）
- フォーカス判定は `src/utils/clipCardDisclosure.ts` が `findActiveTimelineItemWithTransitions` を使う
- 読み込み直したことの検知は、保存しない実行時カウンタ `clipListRestoreEpoch`（`restoreFromSave` でのみ増やす）

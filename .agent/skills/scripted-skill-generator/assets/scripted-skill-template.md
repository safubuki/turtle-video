## 概要

このスキルは、{対象業務} のうち確率論によるブレを許さない {取得/変換/集計/検証} を `scripts/{script-name}` に委譲し、文脈に応じた条件設定・例外対応・結果解釈は AI が担当します。

## 役割分担（3層分離）

| 層 | 担当 | 担う処理 |
|----|------|----------|
| 層3: 判断・解釈・対話（確率論） | AI（自然言語） | 要望からの条件推定、必要時の最小限確認、出力や警告の解釈、次の提案 |
| 層2: 可変境界（引数・中間データ） | CLI引数 / 中間ファイル | 期間、対象パス、除外条件、出力形式などの可変パラメータ受け渡し |
| 層1: 決定論コア（固定） | `scripts/{script-name}` | 取得、検証、正規化、計算・集計、固定形式出力、上書き保護 |

## 失敗時の確認ポイント

- 終了コードが `0` 以外の場合は標準エラー出力（stderr）の原因と対象パスを確認する
- 既存の出力ファイル保護で停止した場合は、別名出力するかユーザー確認のうえ `--force` を付ける
- 想定外の入力形式や警告が出た場合は、スクリプトで推測補正せず状況に応じて判断・相談する

## スクリプト更新・見直し条件

- 入力形式、出力列、集計軸、対象 API やプロジェクト構造が変わったとき
- 同じ手作業や例外対応を2回以上繰り返したとき（スクリプトへ追加・昇格）
- 実行のたびにスクリプト本体を書き換えているとき（固定しすぎのサイン → 引数化または AI 判断層へ戻す）
